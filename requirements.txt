#   0.3.18.post0  lange im Einsatz, funktioniert

#                 "Wire format was corrupt" (Issue #199)
#   0.4.3.post0   am 08.08.2026 vollständig geprüft (siehe UPGRADE-TEST.md);
#                 seit 07.11.2026 von WhatsApp abgewiesen: "Client outdated
#                 (405)" - die mitgelieferte whatsmeow-Fassung vom 09.07.
#                 meldet sich als Client 2.3000.1042386815 an
#   0.5.2         whatsmeow vom 21.09. (Client 2.3000.1047769893); die
#                 Schnittstellen, die der Ticker nutzt, sind unverändert.
#                 Behebt nebenbei zwei Fehler, die wir upstream gemeldet
#                 hatten: kein Go-Absturz mehr bei inhaltslosen
#                 Kanalnachrichten (neonize#210/#211), und Sprachnachrichten
#                 aus Kanälen laden ohne "invalid media hmac" (whatsmeow#1229)
#   0.6.1-0.10.0  (02./03.11.2026) DIESELBE whatsmeow vom 21.09. - gegen eine
#                 erneute 405 hilft keine davon
#   0.11.0-0.12.4 (20.11.2026) whatsmeow vom 16.11. (Client
#                 2.3000.1054751086), alle fünf dieselbe. Schnittstellen,
#                 die der Ticker nutzt, unverändert; neu sind nur Ereignisse
#                 und Funktionen, die er nicht braucht. Bringt cryptography
#                 und pycryptodome als Abhängigkeiten mit.
# Welche whatsmeow eine neue Fassung mitbringt, prüft der Wächter
# (skyrelay-heartbeat.py --status).

# wieder, hilft nur eine neonize-Fassung mit neuerer whatsmeow-Anbindung.
# Vor einem Wechsel die Sitzungsdatei sichern: Das Datenbankschema ändert sich.

# Datei also weiter lesen können - im Zweifel hilft eine neue Kopplung.

# --- Zeichenzaehlung (empfohlen, aber nicht zwingend) ---
# Bluesky begrenzt einen Beitrag auf 300 Graphemes und 3000 Bytes. Graphemes
# sind das, was ein Mensch als EIN Zeichen sieht - "👨‍👩‍👧‍👦" besteht aus sieben
# Codepoints und zaehlt trotzdem als eines. Python bringt dafuer nichts mit;
# regex kann es ueber \X nach dem Unicode-Standard UAX #29.
# Fehlt das Paket, rechnet SkyRelay mit einer eingebauten Naeherung weiter, die
# alles abdeckt, was in Beitraegen real vorkommt (Umlaute, Emoji mit
# Hautfarbe, ZWJ-Folgen, Flaggen). Der Bot laeuft also auch ohne - ein
# "git pull" ohne "pip install" bleibt gefahrlos.
regex>=2024.11.6

# --- Oberflaeche des Einrichtungsassistenten ---

# Formular rechts, Erklaerung unter jedem Feld. Reines Python, laeuft ab 3.9
# und ueber SSH. Fehlt das Paket, fragt der Assistent zeilenweise - er laeuft
# also auch ohne, nur unbequemer.
